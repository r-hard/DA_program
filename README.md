# A/B测试分析项目

## 项目概述

本项目通过A/B测试分析网页优化效果，帮助公司决策是否应该使用新页面、保留旧页面或延长测试时间。

## 数据结构

### 主要数据集 (ab_data.csv)
| 字段 | 类型 | 描述 |
|------|------|------|
| user_id | 数值 | 用户唯一标识符 |
| timestamp | 字符串 | 用户访问时间 |
| group | 字符串 | 用户分组（control/treatment） |
| landing_page | 字符串 | 访问页面（old_page/new_page） |
| converted | 数值 | 是否转化（1=转化，0=未转化） |

### 国家数据集 (countries.csv)
| 字段 | 类型 | 描述 |
|------|------|------|
| user_id | 数值 | 用户唯一标识符 |
| country | 字符串 | 用户所在国家（UK/US/CA） |

## 分析流程

### 1. 数据探索与清洗
- **数据质量检查**：验证数据完整性，检查缺失值和重复数据
- **一致性验证**：确保treatment组对应new_page，control组对应old_page
- **重复用户处理**：识别并处理重复的用户记录

### 2. 描述性统计分析
- **总体转化率**：计算所有用户的转化比例
- **分组转化率**：分别计算control组和treatment组的转化率
- **差异分析**：比较新旧页面的转化率差异

### 3. 假设检验
- **零假设(H0)**：旧页面效果不差于新页面 (p_old >= p_new)
- **备择假设(H1)**：新页面效果更好 (p_new > p_old)
- **显著性水平**：α = 0.05
- **检验方法**：
  - 蒙特卡洛模拟（1000次迭代）
  - 比例z检验

### 4. 逻辑回归分析
- **基础模型**：converted ~ ab_page
- **扩展模型**：加入国家变量（CA、UK、US）
- **交互模型**：分析页面类型与国家的交互效应

### 5. 交互效应分析
- **国家差异**：探索不同国家用户对新页面的反应差异
- **交互项**：new_page × country，分析跨文化效应

## 主要发现

### 转化率对比
- **总体转化率**：约11.96%
- **旧页面转化率**：约12.04%
- **新页面转化率**：约11.88%
- **差异**：仅0.16%，统计上不显著

### 统计检验结果
- **p值**：大于0.05，无法拒绝零假设
- **z统计量**：未达到显著性阈值
- **结论**：没有足够证据证明新页面优于旧页面

### 回归分析发现
- **页面效应**：ab_page系数不显著
- **国家效应**：国家变量对转化率影响不显著
- **交互效应**：页面与国家的交互作用不显著
